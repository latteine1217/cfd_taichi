## 主要問題

1. ❌ **襟翼離主翼太近**: 重疊 5%，阻塞氣流通道
2. ❌ **縫翼離主翼太遠**: 間隙 7.7%，導流效果減弱
3. ⚠️ **襟翼尺寸偏大**: 35%，超出 single-slotted 標準

---

## 修正方案

### 1. 襟翼位置調整
```python
# 修正前
FLAP_OVERLAP_RATIO = 0.95    # 重疊 5%

# 修正後
FLAP_OVERLAP_RATIO = 1.03    # 分離 3% ✅
FLAP_GAP_Y_RATIO = -0.025    # 增加垂直間隙
```

### 2. 縫翼定位重構
```python
# 修正前: 間隙難以控制
xs, ys = transform_coords(..., translate_x=gap - scale*chord, ...)

# 修正後: 精確控制 TE 位置
1. 先旋轉（無平移）
2. 找到旋轉後的 TE 座標
3. 計算精確平移量
4. 應用最終平移
```

### 3. 襟翼尺寸優化
```python
# 修正前
FLAP_CHORD_RATIO = 0.35      # 35%

# 修正後
FLAP_CHORD_RATIO = 0.30      # 30% ✅
```
