### 性能指標說明

- **粒子初始化**: 一次性操作，通常在模擬開始時執行
- **粒子發射**: 每隔數步執行，創建新粒子
- **粒子推進**: 每步執行，移動所有活躍粒子
- **粒子統計**: 可選操作，統計活躍粒子數
- **完整時間步**: 粒子系統總開銷（發射+推進）
- **數據導出**: 保存數據時的 GPU→CPU 傳輸

### 硬體需求

- **推薦**: Apple M3 或更新（Metal backend）
- **最低**: 支援 CUDA/Vulkan 的 GPU
- **記憶體**: 至少 4 GB GPU 記憶體

### 故障排除

#### Metal backend 初始化失敗
```bash
# 確認 Taichi 版本
python -c "import taichi as ti; print(ti.__version__)"

# 應該是 1.7.4 或更新
```

#### 性能異常低
1. 確認 GPU 驅動已更新
2. 關閉其他 GPU 密集型應用
3. 檢查散熱是否正常（避免降頻）
